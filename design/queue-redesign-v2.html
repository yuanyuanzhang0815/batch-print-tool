v2 相对 v1 的四条修正
  • 金额进固定右对齐轨（54pt，tabular figures，弱字重）。重复金额自动垂直对齐 → 不用加粗、不用 section header，分组感由排版自己长出来。正文里不再重复金额。
  • 类别升为主标题（semibold）。真正的区分信息是「电子发票 / 付款记录 / 订单截图」，不是金额。
  • 砍真缩略图（22pt 里 PDF 只是白纸、截图只是花花小块，不承担识别任务却吃 29pt），金额轨接管这个前导槽位；解析失败时改放文件类型。
  • 砍「中国铁路上海局 · 09/15」这种句子式第二行，改成「来源左贴边吃弹性 + 日期右贴边」，日期变成稳定的竖向扫描点，来源再长也不会把日期挤跑。
四类状态语义（不许串）
  • selected = 这是谁（浅色 inset 底，对应右侧预览）
  • hover = 手在哪（更浅的底 + 效用位出声）
  • modified = 偏离默认（蓝色值，别再加粗加饱和）
  • processing / error = 机器事实（只在右侧效用位，身份区永远不抖）
一条还没解决的张力
  • 「Success is silent」被用来干掉 就绪，但 全部 / 1× 同样每行都在喊。我的暂定判据：机器事实静默，用户决定常显 —— 状态是机器说的，范围/份数是用户自己定的，所以后者该常驻。
